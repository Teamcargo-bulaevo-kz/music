# Выкладывание в Google Play

## Уже сделано в коде

- Только плеер: ассистент, звонки, контакты, календарь, служба специальных возможностей, Shizuku, слово активации и «Доступ ко всем файлам» убраны (последняя версия с ними в теге `archive/frend-assistant`).
- Целевая версия Android 16 (API 36): с 31 августа 2026 Google Play принимает новые приложения и обновления только с ней. Экраны рисуются во всю высоту с отступами от системных панелей.
- Релизная сборка с R8, сжатием ресурсов и подписью из переменных окружения; ключи в репозиторий не попадают.
- Резервная копия Android: разметка и плейлисты переезжают на новый телефон.
- Файлы таблицы и частей для другого ИИ лежат в личной папке приложения и уходят кнопкой «Поделиться», доступ ко всем файлам не нужен.

## Что нужно решить и сделать вам

1. **Идентификатор приложения.** Сейчас `com.example.assistant`, Google Play такой не принимает. Задайте свой в `app/build.gradle.kts` (`playApplicationId`), например `kz.xxx.music`. Пока он учебный, сборка `bundleRelease` остановится сама. После первой публикации менять нельзя.
2. **Ключ ИИ вынести на сервер.** Сейчас ключ Groq вшивается в APK, из готового приложения его можно достать. Перед публикацией запросы разметки должны идти через ваш сервер (адрес и ключ хранятся там). Вшитый ключ нарушает правила Google Play.
3. **Ключ подписи.** Создайте хранилище ключей (`keytool -genkeypair ...`) и сохраните копию в надёжном месте: потеряв его, обновить приложение нельзя. Для сборки в GitHub Actions добавьте секреты `RELEASE_KEYSTORE_BASE64`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`. Рекомендуется включить Play App Signing при создании приложения.
4. **Аккаунт разработчика** Google Play (разовый взнос, проверка личности; для личных аккаунтов перед выходом в продакшн нужен закрытый тест с группой тестировщиков на установленный Google срок, актуальные условия смотрите в Play Console).
5. **Политика конфиденциальности.** Черновик: [PRIVACY_POLICY.md](PRIVACY_POLICY.md). Её нужно разместить по публичной ссылке (например, GitHub Pages) и указать в Play Console.
6. **Анкета «Безопасность данных».** Ответы: приложение отправляет названия, исполнителей и альбомы песен на сервер разметки; аудио и личные данные не собираются; данные не продаются. Если сервер что-то сохраняет, укажите это.
7. **Разрешение «Запись звука».** В декларации поясните: нужно только системному визуализатору для анимации фона, звук с микрофона не записывается. Если Google Play будет возражать, фон перейдёт на условный ритм без этого разрешения.
8. **Карточка приложения:** название, краткое и полное описание, значок 512×512, баннер 1024×500, не менее 2 скриншотов телефона, возрастной рейтинг (анкета), категория «Музыка и аудио».

## Как собрать пакет

1. Задайте `playApplicationId`, добавьте секреты подписи.
2. Actions → Build → Run workflow, включите «Собрать релизный пакет для Google Play».
3. Скачайте `music-release.aab` из Artifacts и загрузите в Play Console (сначала во внутреннее тестирование).
4. Увеличивайте `versionCode` в `app/build.gradle.kts` с каждой загрузкой.
