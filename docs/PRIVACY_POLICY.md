# Политика конфиденциальности приложения «Музыка» (черновик)

Дата: ____ (заполнить). Разработчик: ____ (имя или организация, контактная почта).

**Что приложение читает.** Музыкальные файлы на вашем телефоне (название, исполнитель, альбом, жанр, длительность, обложка) через системную медиатеку. Сами файлы никуда не отправляются.

**Анализ звука.** Темп, настроение и энергия песен определяются прямо на телефоне. Звук и файлы с телефона не отправляются.

**Что отправляется на сервер (если сервер включён).** Для уточнения жанра и настроения названия песен, исполнители, альбомы и длительность отправляются на сервер (____ указать, где он работает и что с данными происходит). Аудио, контакты, место и идентификаторы устройства не отправляются.

**Что хранится на телефоне.** Разметка, оценки, плейлисты и таблица «Музыка.xlsx» лежат в личной папке приложения. Android может копировать их в вашу резервную копию Google, чтобы вернуть после переустановки.

**Запись звука.** Приложение просит это разрешение только для системного анализатора звука, который двигает фон в такт музыке. Микрофон не включается, звук не записывается и не сохраняется.

**Передача третьим лицам.** Данные не продаются и не передаются для рекламы. Для серверного уточнения используется поставщик ИИ (____ указать, например Groq) по условиям его политики.
