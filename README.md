# Музыка

Лёгкий и приятный на вид плеер для музыки, которая лежит на телефоне. Приложение само размечает песни по настроению, жанру и энергичности, собирает подборки («спокойное», «для бега», «для работы») и играет под живой сине-фиолетовый фон, который пляшет в ритм звука.

Приложение готовится к публикации в Google Play (см. [docs/PLAY_RELEASE.md](docs/PLAY_RELEASE.md)).

> Раньше репозиторий был голосовым ассистентом Frend с плеером внутри. Ассистент вынесен: его последняя версия сохранена в теге `archive/frend-assistant`.

## Что умеет

- **Вся музыка телефона** в одном месте: вкладки Треки, Настроение, Жанры, Исполнители, Плейлисты; поиск с транслитом и опечатками («линкин парк» найдёт Linkin Park).
- **Разметка.** ИИ определяет настроение, жанр, энергичность (1–5) и темп. Разметка идёт в фоне, ручные правки и оценки она не перезаписывает. Можно отдать песни другому ИИ (ChatGPT, Gemini, Claude) и вставить его ответ.
- **Плеер:** обложка, перемотка, перемешивание, повтор, очередь, «Ещё такое», таймер сна, лайки, управление из уведомления.
- **Живой фон:** тёмно-синие и фиолетовые градиенты, плавное пламя, которое растёт на ударе и переливается быстрее на громких местах.
- **Таблица `Музыка.xlsx`:** вся разметка в Excel; кнопка «Поделиться» отправляет её куда угодно, при переустановке приложение читает её обратно.
- Работает без интернета, кроме самой ИИ-разметки.

Сейчас настроение определяется по названию, исполнителю и тегам файла. Разбор самого звука (ритм, темп, энергия) прямо на телефоне ещё впереди: он уберёт зависимость от сервера и ключа.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Аудио (`READ_MEDIA_AUDIO`) | прочитать музыку на телефоне |
| Уведомления | управление плеером и ход разметки |
| Интернет | запросы ИИ-разметки |
| Запись звука (`RECORD_AUDIO`) | только чтобы системный анализатор звука двигал фон в ритм; микрофон не слушается и ничего не записывается. Без разрешения фон анимируется условным ритмом |

Доступ ко всем файлам, контакты, звонки, календарь и специальные возможности не используются.

## Устройство кода

Пакет `com.example.assistant` (имя пакета в коде остаётся, идентификатор приложения задаётся отдельно, см. ниже), папка `app/src/main/java/com/example/assistant`:

| Файл | Роль |
|---|---|
| `MusicActivity` | список, вкладки, поиск, меню, мини-плеер |
| `PlayerActivity` | полноэкранный плеер |
| `TrackEditActivity` | характеристики песни |
| `MusicService`, `PlayerState` | воспроизведение, очередь, уведомление |
| `MusicLibrary`, `MusicSearch`, `TextMatch`, `TrackMatcher` | чтение музыки, поиск, сопоставление названий |
| `MusicTags`, `MusicTagger`, `MusicTagService`, `GroqClient` | разметка и хранение тегов |
| `MusicCatalog`, `MusicAiPack`, `FileConvert`, `MusicFiles` | таблица xlsx, файлы для другого ИИ |
| `FlameBackgroundView`, `BeatSource` | живой фон и ритм |
| `Edge` | отступы от системных панелей (экран во всю высоту) |

## Сборка

GitHub Actions (`Build`): тесты и отладочный APK при пуше в `main` и вручную. APK лежит в разделе Artifacts запуска. Ключ ИИ берётся из секрета `GROQ_API_KEY`. Релизный пакет для Google Play собирается вручную (см. docs/PLAY_RELEASE.md).

Локально: `gradle testDebugUnitTest assembleDebug` (Gradle 8.13, JDK 17).
