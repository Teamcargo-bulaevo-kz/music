# Harmonia

Лёгкий и приятный на вид плеер для музыки, которая лежит на телефоне. Определяет настроение, темп и энергию песен по самому звуку (прямо на телефоне, без интернета), собирает подборки под занятие и играет под живой сине-фиолетовый фон, который пляшет в ритм.

Приложение готовится к публикации в Google Play (см. [docs/PLAY_RELEASE.md](docs/PLAY_RELEASE.md)).

> Раньше репозиторий был голосовым ассистентом Frend с плеером внутри. Ассистент вынесен: его последняя версия сохранена в ветке `archive/frend-assistant`.

## Что умеет

- **Вся музыка телефона** в одном месте: вкладки Треки, Настроение, Жанры, Исполнители, Плейлисты; поиск с транслитом и опечатками («линкин парк» найдёт Linkin Park).
- **Анализ по звуку на телефоне** (`LocalMoodAnalyzer`): темп (BPM), энергичность, танцевальность, позитивность, напряжение и процентный профиль настроений (сумма 100%), в том числе смена настроения внутри песни. Звук не покидает телефон.
- **Умные подборки** (⋮ → «Умные подборки»): «Спокойствие · вечер», «Фокус · работа», «Заряд · тренировка», «Танцевальный ритм» и своя подборка по настроению, энергии и диапазону BPM; можно сохранить в папку.
- **Плеер:** обложка, спектр звука волной, профиль настроения, перемотка, перемешивание, повтор, очередь, «Ещё такое», таймер сна, лайки, управление из уведомления.
- **Живой фон:** тёмно-синие и фиолетовые градиенты, плавное пламя, которое растёт на ударе и переливается быстрее на громких местах.
- **Папки и плейлисты, таблица `Музыка.xlsx`:** разметка в Excel; кнопка «Поделиться» отправляет её куда угодно, при переустановке приложение читает её обратно. Можно отдать песни другому ИИ и вставить его ответ.
- **Необязательный сервер** (`server/music-intelligence`): по метаданным (название, исполнитель, альбом) уточняет жанр и настроение. Ключ ИИ живёт только на сервере. Без сервера всё работает на телефоне.

Все функции работают без интернета, кроме необязательного серверного этапа.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Аудио (`READ_MEDIA_AUDIO`) | прочитать музыку на телефоне |
| Уведомления | управление плеером и ход разметки |
| Интернет | только серверное уточнение, если сервер настроен |
| Запись звука (`RECORD_AUDIO`) | только чтобы системный анализатор звука двигал фон и волну в ритм; микрофон не слушается и ничего не записывается. Приложение объясняет это перед запросом. Без разрешения фон анимируется условным ритмом |

Доступ ко всем файлам, контакты, звонки, календарь и специальные возможности не используются.

## Устройство кода

Пакет `com.example.assistant` (имя пакета в коде остаётся, идентификатор приложения задаётся в `app/build.gradle.kts`), папка `app/src/main/java/com/example/assistant`:

| Файл | Роль |
|---|---|
| `MusicActivity` | список, вкладки, поиск, меню, умные подборки, мини-плеер |
| `PlayerActivity` | полноэкранный плеер |
| `TrackEditActivity` | характеристики песни |
| `MusicService`, `PlayerState` | воспроизведение, очередь, уведомление |
| `MusicLibrary`, `MusicSearch`, `TextMatch`, `TrackMatcher` | чтение музыки, поиск, сопоставление названий |
| `LocalMoodAnalyzer`, `MoodProfileView` | анализ звука на телефоне и его показ |
| `MusicTags`, `MusicTagger`, `MusicTagService`, `ServerMusicAnalyzer` | разметка, хранение тегов, серверное уточнение |
| `MusicCatalog`, `MusicAiPack`, `FileConvert`, `MusicFiles` | таблица xlsx, файлы для другого ИИ |
| `FlameBackgroundView`, `SpectrumGlowView`, `BeatSource` | живой фон, волна спектра, анализатор звука |
| `Edge` | отступы от системных панелей (экран во всю высоту) |

## Сборка

GitHub Actions (`Build`): тесты и отладочный APK при пуше в `main`, `music` и `claude/music-flame-ui`, а также вручную. APK лежит в разделе Artifacts запуска. Адрес и токен сервера берутся из секретов `MUSIC_INTELLIGENCE_URL` и `MUSIC_INTELLIGENCE_TOKEN` (необязательно). Релизный пакет для Google Play собирается вручную (см. docs/PLAY_RELEASE.md).

Локально: `gradle testDebugUnitTest assembleDebug` (Gradle 8.13, JDK 17).

В отладочной сборке в меню ⋮ есть пункт «Размер окна (для отладки)».
